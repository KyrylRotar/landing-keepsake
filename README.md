# Keepsake — Digital & Branding Agency

Адаптивна односторінкова вебсторінка дизайн-агенції Keepsake за макетом із Figma.

## Демо

[Переглянути сайт на GitHub Pages](https://kyrylrotar.github.io/landing-keepsake/)

## Технології

- Семантичні HTML5 та CSS3.
- Адаптивна верстка з підходом mobile-first і медіазапитами.
- CSS Grid і Flexbox.
- CSS-змінні для дизайн-токенів.
- Google Fonts: Oswald, Open Sans, Dancing Script.
- Інлайн-SVG для іконок.
- Без JavaScript, фреймворків та UI-бібліотек.

## Реалізовано

- Секції: головний екран, портфоліо, послуги, статистика, клієнти, відгук, журнал і футер.
- Адаптивні макети для мобільного, планшета й десктопа.
- Фільтрація портфоліо засобами CSS через `:checked`.
- Мобільне меню на HTML-елементі `<details>`.
- Стани наведення та видимого клавіатурного фокусу.
- HTML-перевірка email та обов'язкової згоди у формі підписки. Форма демонстраційна й не надсилає дані.
- Ілюстрації портфоліо, створені CSS-засобами.

## Перегляд локально

Відкрийте `index.html` у браузері або запустіть локальний статичний HTTP-сервер із кореневої папки проєкту.
