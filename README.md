# Keepsake — Digital & Branding Agency

Адаптивний лендінг дизайн-агенції Keepsake, зверстаний за макетом із Figma.

## Демо
Демо запуск:

https://kyrylrotar.github.io/landing-keepsake/

## Технології

- HTML5 та CSS3 без JavaScript, фреймворків і UI-бібліотек.
- Mobile-first верстка з контрольними ширинами 375, 768 та 1280 px.
- CSS Grid і Flexbox для розташування секцій та елементів.
- CSS-змінні для кольорів, шрифтів і повторюваних значень.
- Google Fonts: Oswald, Open Sans і Dancing Script.
- Інлайн-SVG для іконок.

## Реалізовано

- Адаптивні секції: портфоліо, послуги, статистика, клієнти, відгук, журнал і футер.
- Фільтрація робіт засобами CSS через `:checked`.
- Мобільне меню на HTML-елементі `<details>`.
- Стани наведення та клавіатурного фокусу.
- Перевірка email і обов'язкової згоди засобами HTML; стани форми відображаються через CSS. Форма демонстраційна й не надсилає дані.
- Ілюстрації портфоліо створені за допомогою CSS-фігур.

## Запуск локально

Відкрийте `index.html` у браузері або запустіть локальний статичний HTTP-сервер із кореневої папки проєкту.

## Публікація на GitHub Pages

1. Завантажте файли проєкту в репозиторій `landing-keepsake`.
2. У репозиторії відкрийте **Settings → Pages**.
3. У блоці **Build and deployment** виберіть **Deploy from a branch**, гілку `main` і папку `/(root)`, потім натисніть **Save**.
4. Після публікації скопіюйте адресу сайту сюди, у розділ «Демо».
